# 公開サイト 設計案（合意前のたたき台）

仮称: **「解体費しらべ」**（サイト名・ドメイン・運営者表記は未定。決まるまでこの仮名）

## 方針
- 社内ツール（`app.py`・`webapp/`・`public/`・Vercel プロジェクト genchi-photo-report）は**触らない**。公開サイトは `kaitai/` 以下に別アプリとして作り、**別の Vercel プロジェクト**（Root Directory = `kaitai`）にする
- 写真の読み取り（`webapp/reading.py`）と解体の数量・概算（`sitekit/demolition.py`・`rfq.py`）は import して再利用。エンジンへの変更は後方互換の追加だけ
- 写真・住所は**保存しない**（メモリ上で処理し、応答後に破棄。ログにも出さない）

## 画面の流れ（スマホ前提・3分）
1. **トップ**: 「家の写真5枚で、解体費の目安がわかる」＋「壊す家から、売れるものが見つかるかも」＋注意書き（概算 ±20%程度）
2. **撮影ガイド**（最重要）: 正面 → 右 → 裏 → 左 → 斜め45° を1枚ずつ案内（イラスト付き）。撮った直後にブラウザ内で簡易チェック（AI を使わないので無料）
   - 暗すぎ・明るすぎ（輝度の平均）、ブレ（エッジ量）、解像度不足、同じ写真の重複
   - 「建物が切れている」「裏がない」は撮影時に本人へ確認（チェックボックス＋見本写真）。AI 読み取り後に、読み取り結果の「見えない面・確信度」から追加撮影のおすすめを出す
3. **かんたん質問**: 住所（市区町村まで可）、構造（わからない可）、家財が残っているか、空き家か、築年（わからない可）
4. **結果**
   - 解体費の目安（安め〜高め）と内訳（建物本体／付帯・外構／家財の処分／アスベスト調査など）
   - 推定した延床・階数・構造と「この写真から見えたこと」
   - **見つかった価値**: 写真から拾った候補（アルミサッシ・鉄部・室外機・古材らしき梁・欄間・灯籠など）と差し引ける目安（幅・時点・出典つき、断定しない）
   - **使えそうな補助金**: 住所の市区町村の制度（データにあれば）＋探し方。「契約前に申請」「要確認」を明記
   - 次の一歩: ①見積依頼書をダウンロード ②一括見積サービスへ（PR表記） ③土地の売却・活用（PR表記） ④建替え相談（運営会社のサービスとして明記）
5. **見積依頼書**: rfq.py を一般向けにした PDF（専門用語を減らし、写真・推定数量・注意点）。**本人がダウンロードして自分で送る**のが基本。業者への送付をサイトが代行する機能は、提携業者が決まってから明示の同意画面つきで追加

## 収益化（設定ファイルで切り替え）
`kaitai/config/monetize.json` に「枠」と「中身」を分けて持つ:
```json
{"slots": {"after_result": ["kaitai_quote", "land_use", "rebuild"]},
 "offers": {"kaitai_quote": {"enabled": false, "label": "解体業者の一括見積", "url": "#PLACEHOLDER", "pr": true, "contract": "未契約"}, ...}}
```
- `contract` が「契約済」かつ URL がプレースホルダでないものだけ本番に表示（**未契約リンクは出ない仕組み**）。クリックは件数だけ数える（個人情報なし）
- 候補: 解体見積アフィリエイト／提携解体業者への送客／土地活用・売却アフィリエイト／ホームランディック建替え相談

## 価値の推定
- AI の読み取り結果に `salvage`（候補・数量の目安・確信度・写真番号）を**追加**（既存の項目は変えない）
- 単価は `kaitai/data/salvage_prices.json`（確認日・出典つき）。表示は「0〜5万円程度」のように幅で。古材・欄間などは「専門店の査定で値がつく可能性」とし金額を断定しない

## 費用上限・ボット対策
| 段 | 内容 | 初期値（要確認） |
|---|---|---|
| 1 | Cloudflare Turnstile（送信時に検証） | — |
| 2 | 1IPあたり1日の回数（Upstash Redis） | 3回 |
| 3 | サイト全体の1日の回数 | 50回 |
| 4 | Anthropic Console 専用ワークスペースの月額上限 | $300 |
| 5 | 写真は端末側で縮小、1回あたり最大8枚・合計 4MB 未満 | — |
上限を超えたら「本日の受付は終了しました」を表示。いずれも環境変数で変えられるようにする。

## 環境変数（依頼者がダッシュボードで設定。値はチャットに書かない）
`ANTHROPIC_API_KEY`（公開サイト専用キー）／`TURNSTILE_SITE_KEY`・`TURNSTILE_SECRET_KEY`／`UPSTASH_REDIS_REST_URL`・`UPSTASH_REDIS_REST_TOKEN`／`DAILY_LIMIT_TOTAL`・`DAILY_LIMIT_PER_IP`／`SITE_MODEL`／`PREVIEW_PASSWORD`（一般公開まではサイト全体を合言葉で保護）

## ページ
トップ／診断（撮影ガイド→結果）／使い方／よくある質問／運営者情報／プライバシーポリシー／利用規約。デザインは白基調・紺と緑のアクセント、社内ツールとは別の見た目。

## 公開までの手順

4. 依頼者が表示・規約・上限を確認 → 合言葉を外して一般公開
