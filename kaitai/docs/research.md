### 1-2. 解体業者への直接送客（成果報酬）
業者が一括見積サイトに払う紹介料は工事費の 5〜20%（一般に 10〜15%、クラッソーネは 2022年時点で 12.5%＋3万円との記事）[3][11]。木造30坪（約150万円）なら成約1件 15〜20万円規模（推測）。ASP 経由より桁が大きいが、業者の選定・契約・紹介料の扱い（建設業法・景表法の表示）を詰める必要あり。

### 1-4. 表示ルール（ステマ規制・2023年10月〜）
- アフィリエイト部分は「広告」「PR」を目立つ位置に明示（末尾だけ・小さい文字は不可）[13][14]
- 自社（ホームランディック）への送客は、運営者を明示し「当社サービスのご案内」として分ける。運営者を伏せた中立サイトから自社へ誘導する形は避ける（推測・安全側）

### 推奨（推測）
主軸＝解体見積案件（解体無料見積ガイド or クラッソーネ）／併設＝土地活用（タウンライフ）・売却（イエウール）／自社枠＝建替え相談（自社広告として明示）／将来＝送客実績ができたら地域の解体業者と直接契約。

## 5. 費用上限・ボット対策・ホスティング
- **Claude API の1回あたり**（写真8枚で入力約2万・出力約1万トークン）: Opus 5.5 ≒ $0.28（約42円）、Sonnet 5.5 ≒ $0.14（約21円）。1日50回なら Opus で月 約$420
- **Cloudflare Turnstile**: 無料・回数無制限、Cloudflare にドメインを載せなくてよい、日本語表示可、サーバー側で siteverify 必須（トークンは300秒・1回限り）
- **回数上限**: Vercel WAF のレート制限は最大10分窓で「1日」は作れない → **Upstash Redis（Vercel Marketplace、無料枠 月50万コマンド）で 1IP/日・全体/日 を数える**。Claude を呼ぶ前に INCR して超過なら 429
- **最後の歯止め**: Anthropic Console で公開サイト専用ワークスペース＋専用キーを作り、月額 spend limit を設定
- **Vercel**: 収益化サイトは Hobby 不可（商用）→ **Pro**。パスワード保護は Pro の有料オプション（月$20）、Vercel Authentication は無料。リクエスト上限 4.5MB → 写真は縮小して合計サイズを画面で確認
