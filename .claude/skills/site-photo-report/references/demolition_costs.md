# 解体工事費用 単価・係数リファレンス（2026-10版）

外観写真から解体の概算見積を出すための単価表です。機械可読版は `data/demolition_unit_prices.json` にあり、数値はこのファイルと同じです。

- 金額は**税抜の目安**です。`[S#]` は末尾の出典番号です。
- 情報が割れている項目は low〜high の幅で示し、mid を選んだ理由を付けました。
- **出典弱**：公開ソースで裏付けが取れず、業界の一般的な目安か、他の数値からの換算で出した値です。
- 1坪＝3.3058㎡ で換算しています。
