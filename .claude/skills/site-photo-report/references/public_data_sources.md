## 共通：タイル座標の計算（WebMercator / XYZ）

```
n = 2**z
x = (lon + 180) / 360 * n
y = (1 - asinh(tan(radians(lat))) / pi) / 2 * n
tile = (int(x), int(y));  画素 = (int(frac(x)*256), int(frac(y)*256))
画素サイズ[m] = 156543.03392 * cos(lat) / 2**z     # 35.6°N で z14≈7.8m, z15≈3.9m, z17≈0.97m, z18≈0.49m
```

成城6丁目の例：z14 = 14545/6453、z15 = 29090/12907、z16 = 58181/25815、z17 = 116362/51630、z18 = 232725/103260。

## 1. 標高タイル（DEM PNG）

- 用途：敷地周辺の高低差グリッド。標高APIを何百回も呼ぶ代わりに、タイルを1〜4枚取って画素を読む。100m四方（1m間隔なら約1万点）でも、DEM1A（z17）のタイル1〜4枚で済む。
- URL：`https://cyberjapandata.gsi.go.jp/xyz/{id}/{z}/{x}/{y}.png`

| id | 内容 | ズーム | テスト地点での結果 |
|---|---|---|---|
| `dem1a_png` | DEM1A 1m（航空レーザ） | **z17のみ**（z18は404） | 200。中心44.24m（標高APIの値は44.2m） |
| `dem5a_png` | DEM5A 5m（航空レーザ） | z15 | 200。中心44.28m、無効画素1.1% |
| `dem5b_png` / `dem5c_png` | DEM5B/5C 5m（写真測量など） | z15 | 成城では404（5Aがある範囲）。石垣島でDEM5Bにフォールバックすることを確認 |
| `dem_png` | DEM10B 10m（全国） | z1〜14 | 200。中心44.9m |
| `dem10b_png`, `dem_gm_png` | — | — | **404**（このIDは存在しない。10mは `dem_png`） |

- 復号式（RGB）：`x = R*65536 + G*256 + B`。`x < 2^23` なら `h = x*0.01`、`x > 2^23` なら `h = (x - 2^24)*0.01`、`x == 2^23`（RGB = 128,0,0）は**無効値**。
- テキスト形式の `dem5a/{z}/{x}/{y}.txt` も200（256×256 のCSV、393KB）。ただし `dem1a/*.txt` は404。PNGの方が軽い。
- フォールバック：点ごとに DEM1A → 5A → 5B → 5C → 10B の順に試す（`elevation_grid` で実装済み）。北海道の山間部と久米島は10B、石垣島は5Bになった。海上ではどれも取れない。
- 注意：DEMは建物・植生を除いた地表面（DTM）。造成後の新しい地形が反映されていない場合がある。
- 出典表記：要（「国土地理院 標高タイル」）。地理院タイルの利用規約に従う（出典を書けば申請不要の範囲が広い）。

## 2. 逆ジオコーダ

- URL：`https://mreversegeocoder.gsi.go.jp/reverse-geocoder/LonLatToAddress?lat={lat}&lon={lon}`
- レスポンス：`{"results":{"muniCd":"13112","lv01Nm":"成城六丁目"}}`（OK）
- 市区町村名は `https://maps.gsi.go.jp/js/muni.js` を引く（OK。`GSI.MUNI_ARRAY["13112"] = '13,東京都,13112,世田谷区';`）。
- 注意：番地までは返らない。海上では結果が空になる。住所検索APIの代表点は町丁目の中心付近なので、住所が町丁目までなら敷地の位置は不確か。写真や地図で敷地を指定し直すこと。出典：国土地理院。

## 3. 用途地域・建ぺい率・容積率・防火地域

### 3a. 不動産情報ライブラリAPI（国交省 reinfolib）— キーが必要
- 例：`https://www.reinfolib.mlit.go.jp/ex-api/external/XKT002?response_format=geojson&z=15&x=29090&y=12907`（用途地域）
- キーなしだと **401**：`"Access denied due to missing subscription key..."`。ヘッダー `Ocp-Apim-Subscription-Key` が必要。キーはサイトで無料申請できる（審査あり）。
- キーがあれば XKT001（都市計画区域）、XKT002（用途地域）、XKT014（防火・準防火）、XKT023（地区計画）などがタイル単位のGeoJSONで取れる。

### 3b. 都市計画決定GISデータ（国交省都市局）— **キー不要。座標から引ける（推奨）**
- ページ：`https://www.mlit.go.jp/toshi/tosiko/toshi_tosiko_tk_000182.html`（同意ページ `..._tk_000087.html` の先）。都道府県ごとに shp / CityGML / **GeoJSON** のzipがある。
- 例：東京都のGeoJSON `https://www.mlit.go.jp/toshi/tosiko/content/001904020.zip`（46.9MB、2.4秒でDL、OK）。zip内のパスは `13_東京都/13112_世田谷区/13112_youto.geojson` など（ファイル名はcp932）。
- レイヤー：youto（用途地域）、bouka（防火）、koudoti（高度地区）、senbiki（区域区分）、tokei（都市計画区域）、chikukei（地区計画）、fuuchichiku（風致地区）、tkbt（特別用途地区）、ryokukachiiki（緑化地域）など。CRSは EPSG:6668（JGD2011 経緯度）。
- 属性の例：`{"YoutoName":"第１種低層住居専用地域","YoutoCode":1,"FAR":"80.0","BCR":"40.0","Citycode":"13112"}`、`{"AreaType":"準防火地域"}`
- 結果：成城6丁目の代表点は第1種低層住居専用地域、建ぺい率40%、容積率80%、高度地区、緑化地域だった（近くの地価公示地点「1低専 40/80」と一致）。
- 注意（使用許諾条件）：参考情報であり、建築確認や重要事項説明には使えない。範囲は概ねの位置。未掲載の自治体・項目がある。高度地区の種別（第1種など）が入っていない場合がある。更新は年1回程度。出典表記：要。
- 実装：`zoning_at()` が初回にzipをDLしてキャッシュする（`~/.cache/site_public_data`）。DLリンクはページのHTMLを解析し、都道府県の行の3つ目のリンクを使う。

### 3c. 国土数値情報 A29 用途地域
- `https://nlftp.mlit.go.jp/ksj/gml/data/A29/A29-19/A29-19_13_GML.zip`（200、45.6MB）。2019年時点なので3bを優先する。

### その他
- 自治体の都市計画情報（例：東京都の「都市計画情報等インターネット提供サービス」、各市の地図サービス）はWebの地図画面だけのところが多く、APIは自治体によって違う。最終確認はここで行う。

## 4. 地価・取引相場

### 4a. 不動産情報ライブラリAPI — キーが必要
- XPT002（地価公示・地価調査ポイント）、XIT001（不動産取引価格情報）、XIT002（成約価格情報）。キーなしでは401（確認済）。実際の取引価格が欲しい場合はこれが必要。

### 4b. 国土数値情報 地価公示 L01／都道府県地価調査 L02 — **キー不要**
- URL：`https://nlftp.mlit.go.jp/ksj/gml/data/L01/L01-{YY}/L01-{YY}_{都道府県コード}_GML.zip`（L02 も同じ形）。`L01-26_13`、`L02-26_13` は200（約2MB。zip内に `.geojson` がある）。全国版は `L01-25_GML.zip`（20.7MB）。
- 主な属性（L01、2025・2026年版で同じ）：007 年、008 価格（円/m²）、009 対前年変動率、025 所在地、027 地積、028 利用現況、047 周辺の土地の利用状況、048 最寄駅、050 駅距離、051 用途地域、052 防火、057 建ぺい率、058 容積率。
- L02：005 年、006 価格、007 変動率、022 所在地、024 地積、025 利用現況。**2026年版で044以降が1つずれた**（2026年版：044 周辺、045 駅、046 距離、047 用途地域、048 防火、051 建ぺい率、052 容積率。2025年版は043〜051）。実装では版で切り替え、用途地域の値の形がおかしいときは警告を出す。
- 結果：成城6丁目の近くでは、地価公示「成城6丁目819番4」が102万円/m²（+7.9%、261m先、1低専 40/80）だった。
- 出典：「国土数値情報（地価公示データ）（国土交通省）」。国土数値情報の利用規約に従う（商用利用可・出典表記が必要。データによって条件が違うので個別に確認）。

## 7. 道路・建物形状

### 7a. 地理院 基盤地図情報ベクトル `experimental_fgd` — OK（推奨のフォールバック）
- `https://cyberjapandata.gsi.go.jp/xyz/experimental_fgd/18/{x}/{y}.geojson`（**z18のみ**、50KB程度）
- クラス：`BldL`（建築物の外周線。LineString。72本中33本が閉じていた。残りはタイル境界で切れた線）、`RdEdg`（道路縁）、`Cntr`（等高線）など。
- 実装では z18 のタイルを 3×3 枚取り、fid ごとに端点をつないでリングに戻し、面積（m²）を計算する。成城では半径40m以内に91棟、道路縁20本が取れた。
- 注意：建物外形は1/2500相当で、更新は数年遅れることがある。面積は外周線の水平投影なので、建築面積の目安にしかならない。

### 7b. 地理院ベクトル `experimental_bvmap`
- `https://cyberjapandata.gsi.go.jp/xyz/experimental_bvmap/{z}/{x}/{y}.pbf`：200（z14、210KB、`application/vnd.mapbox-vector-tile`）。復号には protobuf/MVT ライブラリが必要なので未実装。GeoJSONが欲しいなら7aを使う。

### 7c. OSM Overpass API — **NG（このコンテナから）**

## 8. 航空写真

- `https://cyberjapandata.gsi.go.jp/xyz/seamlessphoto/{z}/{x}/{y}.jpg`
- **z18は200、z19とz20は404**（東京駅・成城・大阪のどれでも同じ）。最大はz18（約0.49m/px）。
- 実装（`aerial_photo`）：zoom=19 を指定するとz18のタイルを4枚つなぎ、2倍に拡大して768pxにする（0.243m/px相当、約186m四方）。画質はz18相当のまま。
- 撮影年は地域によって違う。建物は倒れ込んで写るので、屋根の形から外形を測ると誤差が出る。出典：国土地理院（シームレス空中写真）。
- そのほか、`std`（標準地図）z18 は200。

## 利用規約・出典の要点
- **地理院タイル・地理院API**：出典を書けば多くの用途で申請不要（「国土地理院」と書き、使ったタイル名を添える）。測量法の承認が必要になる使い方（地図の複製として刊行するなど）は別途確認する。サーバーに負荷をかける大量取得は禁止（キャッシュする）。
- **ハザードマップポータル**：Web・アプリで利用できる（商用含む）。出典が必要。土砂災害は国土数値情報と都道府県の条件にも従う。
- **都市計画決定GISデータ**：参考情報。建築確認や重要事項説明に使える保証はない。出典が必要。
- **国土数値情報**：出典が必要。データごとに商用可否の条件がある（地価公示 L01 は「オープンデータ」区分）。
- **J-SHIS**：出典が必要（防災科研）。
- **OSM**：ODbL。「© OpenStreetMap contributors」と表記する。
- `public_data.py` の各関数は、返り値の `attribution` に出典の文言を入れている。レポートの末尾にまとめて載せる。

## 結論（キーなしで取れるか）
- **用途地域・建ぺい率・容積率・防火：キーなしで取れる。** 国交省「都市計画決定GISデータ」のGeoJSON（都道府県別、数十MBを初回だけDL）を使い、座標がどのポリゴンに入るかで判定する。ただし参考情報なので、最終確認は自治体で行う。reinfolib APIはキーが必要。
- **地価：キーなしで取れる。** 国土数値情報の L01/L02（2026年版あり、都道府県別約2MB）で近くの公示地・基準地の価格を得られる。**実取引価格**（取引価格情報・成約価格）はreinfolib APIのキーが必要。
