# 読み取り精度の検証（PDCA 用）

正解の分かる物件（中古住宅の掲載情報・自社の実案件）の外観写真を本番の AI に読ませ、延床・階数・築年・敷地を正解と比べる。

## データの置き場所（git 管理しない）
`jobs/eval/`（`EVAL_DIR` で変更可）に物件ごとのフォルダ `p01/ p02/ …` を作る。
- `photo1.jpg …` 外観写真（読み取りに渡す）
- `truth.json` 正解。最低限 `建物面積_m2`（延床）・`土地面積_m2`・`階数`・`築年月`・`address`。分かれば `各階面積: {"1階_m2":…, "2階_m2":…}`
- 地図の外形も試すときは `jobs/eval/coords.json`（`{"p01": [緯度, 経度], …}`）を作り、`python3 prep_map.py` で `aerial_marked.jpg`・`outlines.json` を用意する

## 実行
```
EVAL_KEY=<社内アクセスキー> python3 run_eval.py v5            # 写真だけ
EVAL_KEY=<社内アクセスキー> EVAL_MAP=1 python3 run_eval.py v5map  # 地図の外形・航空写真あり
python3 score.py v5 v5map                                      # 採点（"ens:a,b" で2回の平均）
```
1件あたり Claude API を1回呼ぶ（入力約1万・出力約1万トークン）。本番の関数は 300 秒で打ち切られるので、effort は medium のまま使う。

## これまでの結果（2026-10 SUUMO 中古戸建て、外観写真のみ）
| 版 | 件数 | 延床の平均誤差 | ±20%以内 | メモ |
|---|---|---|---|---|
| v0 | 12 | 17.6% | 67% | 見えない奥行を決め打ちしていた |
| v1 | 12 | 13.7% | 75% | 屋根の幾何・窓割り・間取りで奥行を確かめる |
| v2 | 30 | 12.3% / 16.1%（同じ指示で2回） | 83% / 67% | 築年別の間取りの目安。回ごとのぶれが大きい |
| v3map | 29 | 24.1% | 48% | 地図の外形（屋根の外周）をそのまま1階にして過大 |
| v4map | 30 | 13.2%（外形を選べた17件は 10.6%） | 80% | 1階床 ≒ 外形×0.72 に補正 |
