# ホームランディック テーマソング（1番・試作）

- `homelandick_theme.mp3` … 歌入り（歌声合成）
- `homelandick_theme_chorus.mp3` … サビだけの切り出し（約20秒。CM・動画の締め用）
- `homelandick_theme_vocal.mp3` … 歌のみ
- `homelandick_theme_karaoke.mp3` … 伴奏のみ（歌入れ用）
- `homelandick_theme.musicxml` … 歌のパート（歌詞つき楽譜）。Synthesizer V・NEUTRINO などの歌声合成ソフトや楽譜ソフトに読み込める
- `homelandick_theme.mid` … メロディ（歌詞つき）＋コード
- `theme_song.py` … 曲そのもの（歌詞・旋律・コード・編曲・歌声合成）。`pip install numpy pysinsy && python song/theme_song.py` で作り直す

歌声は pysinsy（HMM 歌声合成 Sinsy と付属の女声）。機械的な声なので、本番は MusicXML を新しい歌声合成ソフトに読ませるか、人が歌う想定。

92BPM・4/4・約1分55秒。ト長調 → サビのあとイ長調へ転調。
歌の音域は C4〜D5（歌声合成の声が安定する範囲に合わせてある）。

| 小節 | 部分 | 内容 |
|---|---|---|
| 1–4 | イントロ | モチーフをオルゴールのように小さく |
| 5–12 | Aメロ 1 | 七五調の主題。ピアノ中心 |
| 13–20 | Aメロ 2 | 同じ主題に別の歌詞。弦とリズムが入る |
| 21–24 | Bメロ | 長い音でサビへ |
| 25–32 | サビ | 王道進行（F–G–Em–Am）。社名で始まる短いフック、手拍子 |
| 33–36 | モチーフ（転調） | イントロの旋律がオーケストラで戻ってくる |
| 37–40 | サビの後半 | 転調後にもう一度 |
| 41–42 | 結び | |

モチーフ（`theme_song.py` の `MOTIF`）が「YouTube 冒頭のBGM」の差し込み口。**いまは仮の旋律**（本物のBGMは未入手。
YouTube からはこの環境で取得できない）。音源を `song/opening_bgm.*` として置けば、旋律・調・テンポを解析して
`MOTIF`／`MOTIF_CH`／`BPM`／`KEY` を合わせる。
