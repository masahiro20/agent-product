# ホームランディック テーマソング（1番・試作）

- `homelandick_theme.mp3` … 伴奏＋ガイドメロディ（歌の旋律を笛の音で鳴らしている。歌声は入っていない）
- `homelandick_theme_karaoke.mp3` … 伴奏のみ（歌入れ用）
- `homelandick_theme.mid` … メロディ（歌詞つき）＋コード。DAW・歌声合成ソフトに読み込める
- `theme_song.py` … 曲そのもの（歌詞・旋律・コード・編曲）。`python song/theme_song.py` で作り直す（numpy のみ）

80BPM・4/4・約2分。ハ長調 → サビのあとニ長調へ転調。

## 構成

| 小節 | 部分 | 内容 |
|---|---|---|
| 1–4 | イントロ | モチーフをオルゴールのように小さく |
| 5–12 | Aメロ | ピアノ中心 |
| 13–20 | A' | 弦とリズムが入る |
| 21–24 | Bメロ | サビへ |
| 25–32 | サビ | |
| 33–36 | モチーフ（転調） | イントロの旋律がオーケストラで戻ってくる |
| 37–40 | 結び | |

モチーフ（`theme_song.py` の `MOTIF`）が「YouTube 冒頭のBGM」の差し込み口。**いまは仮の旋律**で、
本物のBGMの旋律・調・テンポが分かったら `MOTIF`／`MOTIF_CH`／`BPM` を書き換えて曲全体を合わせる。
